🤔 What is this?

A skill that gives Claude a "research partner" — and makes the two of them pass notes automatically.

Think of it like this

Imagine you have two expert assistants. One is brilliant at going online, watching videos, reading massive documents, and coming back with a full research report. The other is brilliant at writing code, making decisions, and building things from a plan.

This skill is the manager who decides which assistant gets each task, makes sure they share notes, and keeps everything organised in one place. You just describe what you need — the rest happens automatically.

🔵

Gemini does the research

Browse the web, watch YouTube videos, analyse screenshots, read giant files, write first drafts. It has a massive memory and can search Google in real time.

🟣

Claude does the building

Write code, make architecture decisions, reason through tricky problems, test and polish. It takes Gemini's research and turns it into something real.

🤖

Fully automatic

You never pick which AI to use. Just describe your task in plain language — Claude figures out if Gemini should help and handles it.

📁

Each project stays separate

Working on two games at once? Each gets its own folder. Research for Game A never mixes with Game B.

💾

Nothing is forgotten

Everything Gemini finds is saved to disk automatically. Next session, both AIs pick up exactly where you left off.

📋

Ready-made prompts

Need a game design doc? Competitor research? Asset review? Fill in a template — Gemini does the rest in the right format.

⚡ How does it work?

Behind the scenes, every task goes through a simple chain. You only see the result.

💬

You ask for something

"Research the top mobile puzzle games in 2025" or "Design an energy system for my game"

C

Claude decides the best approach

Three quick questions tell Claude if this is a simple task, a research task, or a complex one that needs deep thinking. It picks the right Gemini mode automatically.

C

Claude prepares a sharp prompt (for complex tasks)

Before sending the task to Gemini, Claude uses a brainstorming skill to make the question as clear and precise as possible. Vague questions get vague answers — this step fixes that.

G

Gemini does the work

Gemini searches the web, analyses your video, writes the design doc — whatever was needed. It saves the full result to your project folder automatically.

C

Claude turns the output into action (when needed)

If Gemini wrote a spec or design doc, Claude converts it into a step-by-step implementation plan so it's ready to build from.

💾

Memory is updated — always

Claude updates the shared memory file so next session, both AIs know exactly what was done, what decisions were made, and what's still open.

✅

You see one clean result. All the routing, prompt-writing, model selection, and file-saving happens invisibly. The only thing you see is a brief message like "🤖 Delegating to Gemini — researching top mobile puzzle games" and then the answer.

Not sure which AI will handle your task?

You don't need to know — Claude decides. But if you're curious, here's the simple rule:

Claude asks itself three questions:

Is this a huge amount of content to process — more than a book?
→ Gemini Pro
Does this need searching the web for current information?
→ Gemini Pro

💾 Where does it save things?

Everything is saved in a folder called AI-Context — either inside your current project, or in your home folder if you're not in a project.

📁

Inside a project (a folder with a .git file, CLAUDE.md, or package.json)?
→ Everything saves to YourProject/AI-Context/

Not in a specific project?
→ Everything saves to ~/AI-Context/ (your home folder)

Inside AI-Context, you'll find:

🧠

gemini-memory.md

Gemini's running memory. It reads this at the start of every session to remember what was done before. Claude also reads it.

🔍

research/

Full research reports from web searches, dated and named.

🎮

game-design/

GDD sections, mechanic specs, feature designs written by Gemini.

🖼️

analysis/

Image and video review outputs — one file per asset reviewed.

⚠️

Why is saving so important? Gemini has no memory on its own — it forgets everything when a session ends. This skill forces it to save every result to disk. The next time you open the project, Gemini reads those files and instantly knows your game, your decisions, and your progress.

🔧 Getting started

One-time setup. Takes about 5 minutes. After that, just talk to Claude normally.

1

Copy the skill into your Claude skills folder

This is the folder where Claude looks for custom skills. Copy the entire delegate-to-gemini folder into it.

Windows: Copy-Item -Recurse delegate-to-gemini "$HOME\.claude\skills\"

Mac / Linux: cp -r delegate-to-gemini ~/.claude/skills/
2

Run the setup script

This script installs everything you need — the Gemini CLI tool, the Python helper for image/video analysis, and your output folders. It will guide you through each step.

Windows: python "$HOME\.claude\skills\delegate-to-gemini\setup.py"

Mac / Linux: python ~/.claude/skills/delegate-to-gemini/setup.py
3

Log in to Gemini with your Google account

Open a terminal, type gemini, then type /auth and sign in with your Google account in the browser that opens. This is your own personal login — nothing is shared. You only need to do this once.

4

Get a free Gemini API key (for images & videos only)

Go to aistudio.google.com/apikey, create a free key, and then paste it into the api-key.txt file that setup.py creates for you. You only need this for image and video analysis — the regular web research works without it.

Your API key is stored privately on your machine. It is never put into any shared file or the GitHub repo.

5

Open Claude Code in your project and start asking

That's it. Open Claude Code inside your project folder and just describe what you need. The skill is loaded automatically.

✅

Already have Gemini CLI installed? You can skip straight to step 5 and just make sure gemini-analyze.py exists at ~/.claude/tools/gemini-analyze.py. If it doesn't, run setup.py anyway — it only installs what's missing.

🐙 Sharing on GitHub

Yes — you can copy this skill folder to any directory and upload it to GitHub. It was built to be shared.

The skill folder contains no personal information, no API keys, and no login credentials. Anyone who downloads it runs the setup script to connect their own Google account and API key on their own machine.

What to include and what to leave out

✅ SKILL.md The skill itself — this is what Claude reads
✅ setup.py The installer — users run this to get set up
✅ gemini-analyze.py The image/video helper script
✅ README.md & docs.html Documentation
🚫 .claude/settings.local.json Contains your local file paths — don't share
🚫 docs/superpowers/ Internal planning notes — not needed publicly
🚫 ~/.config/delegate-to-gemini/api-key.txt Your API key — this is outside the folder anyway, never in the repo

How to publish it

1

Copy the folder to a new location

Copy ~/.claude/skills/delegate-to-gemini to a new folder (e.g. your Projects folder). This keeps your installed copy separate from the one you're publishing.

2

Add a .gitignore file

Create a file called .gitignore in the folder with these lines: .claude/ and docs/superpowers/ — this keeps the internal files out of the repo.

3

Create the repo and push

Initialise a git repo in the folder, add your files, commit, and push to GitHub as normal. Anyone who clones it gets a clean copy with no personal data.

💡

For people installing from your GitHub repo: Clone → copy the folder into ~/.claude/skills/ → run setup.py. Done. Their credentials stay on their machine.

❓ Common questions

Things people ask when they first use this skill.

Q
Do I need to tell Claude when to use Gemini?
No. Just describe your task in plain English. Claude runs a quick 3-question check and decides automatically. You'll see a message like "🤖 Delegating to Gemini Pro" when it does.
Q
Will this cost me money?
Gemini Flash (used for quick tasks and images) is on the free tier — no cost. Gemini Pro (used for deep research and writing) counts against your Google account's daily quota. If you need more, Google AI Pro is $20/month. You already have Claude Code — no extra cost there.
Q
What happens when Gemini hits its daily limit?
Claude will tell you immediately and suggest either switching to the free Flash model or waiting for the quota to reset. Before stopping, it saves everything to your project memory so nothing is lost. Next session picks up exactly where you left off.
Q
Can I use this across multiple projects?
Yes — and it stays completely separate. Open Project A and all research goes into Project A's AI-Context folder. Open Project B and the same happens for Project B. They never mix.
Q
What is the "AI-Context" folder?
It's the shared memory folder between Gemini and Claude. Gemini saves everything it produces there. Claude reads from it when you say things like "use my research" or "continue where we left off". Think of it as a shared notepad that both AIs can read and write.
Q
Is my data safe? Does Gemini see my private files?
Gemini only sees what Claude explicitly sends to it — the task description and the project context you've built up in AI-Context. It does not scan your hard drive. Your API key is stored locally in a private config folder and is never sent anywhere except Google's API.
Q
Something's not working. What do I try first?
Run the setup script again — it only installs what's missing, so it's safe to re-run:
Windows: python "$HOME\.claude\skills\delegate-to-gemini\setup.py"
Mac / Linux: python ~/.claude/skills/delegate-to-gemini/setup.py

If Gemini says it's not logged in, open a terminal and run gemini then type /auth.
