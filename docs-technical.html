🧠 What Is This Skill?

A Claude Code skill that orchestrates a two-model AI pipeline for game development and software projects.

delegate-to-gemini is a Claude Code skill that tells Claude when and how to hand tasks off to Google's Gemini CLI — and how to bring the results back into a shared memory bridge for Claude to act on.

Instead of forcing one model to do everything, this skill routes each task to the model best suited for it. It auto-selects between three model tiers (Flash / Pro / Pro+Thinking), invokes Superpowers skills on both sides of the Gemini call to sharpen prompts and strengthen output, and scopes everything to your current project directory so multiple projects never mix.

🤖

Two Models, One Workflow

Gemini handles massive ingestion and live research. Claude handles reasoning, architecture, and code generation.

⚡

3-Tier Auto Routing

Flash for lightweight tasks, Pro for research and drafting, Pro+Thinking for complex specs. Decided by a 3-question flow, not guesswork.

🧠

Superpowers Pipeline

Brainstorming sharpens the prompt before Gemini runs. Writing-plans turns Gemini's output into an actionable implementation plan.

📋

Task-Type Templates

Ready-made prompt templates for Game Design, Research, and Asset Review — pre-filled with context and output formats.

📁

Project-Scoped Context

All output goes into your project's AI-Context/ folder. Open a different project — get that project's context. Nothing mixes.

💾

Persistent Memory Bridge

Gemini's work saves to disk after every task — mandatory. Claude reads it on demand. Nothing is ever lost between sessions.

⚡ How the Workflow Works

A clean two-phase pipeline with a project-scoped memory bridge in between.

🔵 Gemini Phase

  • Ideation & brainstorming
  • Web research (live Google Search)
  • Drafting specs, GDDs, docs
  • Image analysis (UI, screenshots)
  • Video analysis (gameplay, refs)
  • YouTube video ingestion
  • Massive file summarization
→

🟣 Claude Phase

  • Code writing & generation
  • System architecture design
  • Logical reasoning & nuance
  • Polishing & refactoring
  • Testing & QA
  • Making product-ready
  • Multi-step agentic tasks
$AI_CONTEXT/  —  project-scoped or global memory bridge
research/  ·  ideation/  ·  analysis/  ·  drafts/  ·  game-design/  ·  gemini-memory.md
💡

When Claude is loaded inside a project folder, $AI_CONTEXT resolves to <project>/AI-Context/. Outside a project it falls back to ~/AI-Context/. Every project keeps its own research, specs, and memory — fully isolated.

🤖 Model Selection & Routing

Three model tiers, selected by a 3-question decision flow before every delegation.

3-Question Routing Flow

Before every delegation, Claude runs these three questions in order. The first YES wins.

Run before every Gemini call:

1
Is input or output > 50k tokens?
→ Pro
if no, continue ↓
2
Does this need web search or multi-source synthesis?
→ Pro
if no, continue ↓
3
Is this a hard reasoning task — complex spec, deep analysis, architecture decision?
→ Pro + --thinking
if no ↓
⚡ Everything else → Flash

Three Model Tiers

⚡ Flash

gemini-2.5-flash · Free tier · Fast
  • Quick factual questions
  • Image analysis (UI, screenshots)
  • Short summaries under 50k tokens
  • Simple one-shot tasks
  • Second opinion / quick checks

🔮 Pro

gemini-2.5-pro · Uses daily quota
  • Web research + synthesis
  • Deep brainstorming sessions
  • Spec / GDD writing
  • Video & YouTube analysis
  • Large file summarization >50k
  • Competitor analysis

🧠 Pro + Thinking

gemini-2.5-pro --thinking · Expensive — use deliberately
  • Complex system specs
  • Deep architectural decisions
  • Hard multi-step reasoning
  • Always: brainstorm first

Token Economy Rules

SituationRuleWhy
Flash taskSkip brainstorming — call directlyOverhead not worth it for lightweight tasks
Pro task — clear promptCall directlyNo brainstorming needed if intent is unambiguous
Pro task — complex or ambiguousInvoke superpowers:brainstorming firstBetter input → better output → less cleanup
Pro + Thinking taskAlways invoke superpowers:brainstorming firstExpensive calls need sharp, precise prompts
Multiple related tasks in one sessionBatch into one Gemini callPreserves daily quota; Gemini handles multi-part prompts well

🧠 Superpowers Integration

Superpowers skills act as the intelligence layer on both sides of every Gemini call.

Two Superpowers skills wrap the Gemini call to dramatically improve output quality:

  • superpowers:brainstorming — runs before the Gemini call on complex tasks, turning an ambiguous request into a precise, structured prompt
  • superpowers:writing-plans — runs after the Gemini call when output is a spec or doc, converting it into an actionable implementation plan

Full Pipeline (complex tasks)

S

Game Design Template

$date = Get-Date -Format "yyyy-MM-dd"
$slug = "gdd-[feature-slug]"
$resolvedContext = $AI_CONTEXT

$prompt = @"
You are a senior game designer collaborating on [GAME NAME].

GAME CONTEXT:
- Genre: [e.g. mobile puzzle, action RPG]
- Platform: [e.g. iOS/Android, PC]
- Target audience: [e.g. casual players 25-40]
- Current phase: [e.g. pre-production, alpha]
- Core loop: [1-2 sentences]

TASK:
[Describe what to design]

OUTPUT FORMAT:
## Overview  ## Core Mechanics  ## Player Experience
## Balance   ## Monetisation Hooks  ## Edge Cases  ## Open Questions

AFTER COMPLETING:
Save to $resolvedContext\game-design\${date}_${slug}.md
Append 3-5 bullet summary to $resolvedContext\gemini-memory.md under today's date
"@

$result = gemini --yolo --thinking $prompt --output-format text *>&1
$result | Where-Object { $_ -notmatch "^Loaded cached credentials" }

📁 Project-Scoped Context

Every project gets its own AI-Context folder. Work on 3 games? Each one stays separate.

When Claude is opened in a directory that contains a project marker (.git, CLAUDE.md, package.json, project.json, or CMakeLists.txt), all Gemini output is routed into that project's AI-Context/ folder.

🔧 Installation & Setup

One-time setup per machine. Each user provides their own credentials — nothing shared, nothing in the repo.

1

Copy the skill folder into your Claude skills directory

Windows: Copy-Item -Recurse delegate-to-gemini "$HOME\.claude\skills\"
macOS / Linux: cp -r delegate-to-gemini ~/.claude/skills/

Result: ~/.claude/skills/delegate-to-gemini/SKILL.md must exist for Claude Code to auto-load it.

2

Run the setup wizard

Windows: python "$HOME\.claude\skills\delegate-to-gemini\setup.py"
macOS / Linux: python ~/.claude/skills/delegate-to-gemini/setup.py

Installs Gemini CLI (if missing), google-genai pip package, copies gemini-analyze.py to ~/.claude/tools/, creates ~/AI-Context/ folder structure, and stores your API key in ~/.config/delegate-to-gemini/.env.

3

Log in to Gemini CLI (OAuth — one-time)

Run gemini → type /auth → sign in with your Google account. Your own credentials only — not shared. Used for all CLI calls; no API key needed for the CLI.

4

Get a Gemini API key (image & video analysis only)

Visit aistudio.google.com/apikey, create a free key, paste when setup.py asks. Only gemini-analyze.py uses this. Stored in ~/.config/delegate-to-gemini/.env.

  • Windows: file is under your user profile — private by default
  • macOS / Linux: run chmod 600 ~/.config/delegate-to-gemini/.env after setup
5

Open Claude Code inside your project

Navigate to your project folder and start Claude Code. Skill auto-loads from ~/.claude/skills/. AI-Context/ is created on first delegation.

Mandatory Step 6 — Memory Update Protocol

After every Gemini call — whether it succeeds or hits quota — Claude executes both of these before reporting back:

  1. Update $AI_CONTEXT/gemini-memory.md — add today's session under ## Recent Sessions, update ## Active Work, log decisions/open questions
  2. Update Claude project memory — write what was done, what's next, any blockers
⚠️

A quota reset without Step 6 means lost context. With Step 6, both AIs pick up exactly where they left off in the next session.
